## Configuration

### Kimi AI Setup
1. Navigate to **Settings** page after login
2. Enter your NVIDIA NIM API Key
3. Configure Agentic Mode and Memory preferences
4. Click "Save Configuration"

**API Endpoint:** `https://integrate.api.nvidia.com/v1/chat/completions`  
**Model:** `moonshotai/kimi-k2.5`

## Usage Guide

### Creating a Case
1. Go to **Dashboard** → Click "New Case"
2. Enter case name and description
3. Add entities (domains, IPs, emails)
4. Click on entity dots (⋮) to access tools
5. Use "Ask Kimi AI" for intelligent analysis

### Using Notes with AI
1. Navigate to **Notes** section
2. Create a note describing findings
3. Click "Ask Kimi: Analyze this note"
4. Get actionable next-step suggestions

### Generating Reports
1. Open any case
2. Click "Generate Report"
3. Report includes executive summary, findings, and AI insights
4. Download as HTML or view in browser
